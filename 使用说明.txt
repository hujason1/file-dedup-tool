文件查重工具 1.4 使用说明
========================================

一、这是什么
    一个单文件的 Windows 查重工具（文件查重工具.exe），双击即可运行，不用安装、
    不用 .NET 运行时以外的任何组件。用来找出照片、视频、文档、音频、压缩包等
    互相重复的文件，显示每个副本的完整路径，并按你的选择删除多余的副本。

二、顶部菜单
    窗口顶部有一排菜单：文件 / 视图 / 语言 / 关于（英文界面下为 File / View /
    Language / Help），全部功能都能在这里找到。

    1) 文件
       - 编辑：复制选中路径、全选勾选、全不选、清空扫描结果
       - 选择助手…："按规则自动勾选"的完整版，可挑保留规则、每组保留几份，
         并在应用前预览会删多少文件、能省多少空间
       - 字体大小：较小(8) / 标准(9) / 较大(10.5) / 特大(12)
       - 字体设置…：列出系统已安装的字体，可挑字体 + 字号，右侧实时预览
       - 导出清单(CSV)…：把当前结果存成 CSV（1.4 起顶部带本次扫描的汇总）
       - 扫描报告…：把本次扫描的统计数字与清单整理成一段文字，可一键复制
       - 退出
    2) 视图
       - 简约模式：1.4 原来的界面（蓝色渐变大横幅 + 方角卡片 + 方角按钮，浅色）
       - 白色主题（默认）：青灰配色 + 渐变大横幅 + 白色圆角描边卡片，按钮为深青底白字
       - 深色主题：深色界面（夜里看更省眼）
       - 自定义主题…：自己选背景色，还能挑一张图片当背景（显示在卡片四周）
       - 恢复默认背景：清掉自定义背景图
       - 列显示：勾选哪些列显示（删除、组、文件名、路径、大小、修改时间、
         创建时间、状态，其中路径与状态固定显示，其余可自由开关）
       - 恢复默认列宽：把表格列宽一键回到初始值
       - 用鼠标左键按住表格的列头（删除 / 组 / 文件名 / 大小 / 修改时间 / 创建时间 /
         状态…）左右拖动，就能把这一列挪到别的位置；松手即生效，顺序会记住，
         下次打开还是你排的样子
       - 恢复默认列序：把列顺序一键回到 删除 / 组 / 文件名 / 路径 / 大小 / 修改时间 /
         创建时间 / 状态
       - 三套主题（简约/白色/深色）与自定义主题互斥，勾中哪套就记哪套，
         下次打开还是那套；运行中随时切换，不用重启
       - 切换主题只换皮肤，不会动窗口大小和位置：窗口原来多大、在哪，
         切完还是多大、在哪（不会变成铺满全屏）
       - 自定义主题里勾上“半透明玻璃效果”，卡片会变成半透明、透出背景图的模糊影像；
         下面的“透明度”滑杆可在 0%（完全不透明）到 100%（完全透明）之间随意调，
         建议 20%–50%，太高会让文字压在照片上难辨
       - 深色/自定义主题下窗口标题栏也会跟着变深，文字一律跟随主题配色
    3) 语言
       - 简体中文 / 繁體中文 / English / 日本語 / Русский（俄语）/ 한국어（韩语），
         切换后界面文字、表格列名、状态、进度提示、弹窗一起换，不用重启
         （韩语界面会自动把中文字体换成 Malgun Gothic，字形才不会歪）
    4) 关于
       - 版本说明：显示当前版本 1.4 与这一版的改动内容，可直接进入"关于软件"
       - 关于软件：软件定位、使用要点、支持的全部文件格式清单（图片/视频/
         文档/音频/压缩包，共约 380 种），以及开发者与各平台主页（可点击打开）
       - 检查更新：检查是否有新版本（当前为本地单机版，没有在线升级服务器）
       - 关于作者：开发者与主页、照片网站、微博/抖音/小红书账号

    提示：主题、语言、字体、背景这些选择会记在
    %LOCALAPPDATA%\FileDedupTool\settings.ini 里，下次打开还是上次的样子。
    想恢复初始状态，直接把这个文件删掉即可。

三、怎么用（3 步）
    1. 把要检查的文件夹拖进窗口左侧的"扫描范围"列表，或点"添加文件夹"选择；
       支持一次添加多个文件夹，也可以直接把文件拖进来（取其所在目录）。
    2. 选择文件类型（图片/视频/文档/音频默认勾选）。照片想按"画面"而不是"字节"查重，
       勾上"相似图片（感知哈希）"，再选严格/标准/宽松三档阈值。需要时在"补充扩展名"里填
       自己的扩展名（例：psd,ai）。想连陌生后缀、改了名/改了后缀的文件一起查，
       勾上"全文件扫描"。
    3. 点"开始扫描"。扫描结束后，重复的文件会按组显示在下方的表格里；
       选中任意一行，下方的"对比预览"会并排显示缩略图与拍摄参数。
       1.4 起扫描完成的瞬间会弹出一次"扫描报告"：扫描了多少文件、占多大、
       多少组、多少项重复、能释放多少、花了多少秒，可复制走；不想要就在
       报告里取消勾选"扫描完成后自动显示"，下次不再弹。

    扫描过程中左下角有三个按钮：
       - 开始扫描：扫描期间自动变灰，结束后恢复。
       - 暂停 / 继续：扫到大目录时可以临时暂停，按钮变成"继续"，
         此时扫描线程原地挂起、不再读磁盘，几乎不占 CPU 和硬盘，
         点"继续"从停下的地方接着扫，已扫到的结果不会丢。
       - 取消扫描：中止本次扫描（暂停中也能直接取消），
         状态栏显示"已取消扫描。"，界面立即恢复可用。

四、结果表格怎么看
    - "组"列相同的行，内容完全一样（字节级一致），互为副本；
      勾了"相似图片"后，还会有"画面相似"的组（状态列显示"相似 96%"）。
    - 右上角"全部结果 / 仅精确重复 / 仅相似图片"下拉可切换只看哪一类。
    - "完整路径"列显示所在位置，列宽不够时路径会被省略号截断；
      选中任意一行，表格下方会用一行文字显示该文件的完整路径（点击即复制）。
    - 表格列从左到右：删除（勾选框）/ 组 / 文件名 / 完整路径 / 大小 /
      修改时间 / 创建时间 / 状态。1.4 新增"创建时间"列（文件在磁盘上的创建时间，
      取不到时退回修改时间），可在"视图 → 列显示"里随时开关任意列。
    - 列宽可以拖；关掉窗口时会连同窗口大小、排序方式、保留规则一起记住，
      下次打开还是上次的样子（想复位点"视图 → 恢复默认列宽"）。
    - 鼠标悬停在路径上会显示完整路径；双击行可直接打开该文件。
    - 右键菜单：打开文件 / 打开所在文件夹 / 复制完整路径 /
      只保留这一份 / 取消本组全部勾选。

五、对比预览（缩略图 + 拍摄参数）
    选中表格里的任意一行，表格下方的"对比预览"会显示这一组的最多 4 个文件：
    - 左边并排的缩略图：文件名、分辨率、文件大小、保留/待删除状态，一眼看出哪张是哪张；
      鼠标悬停看完整路径，双击缩略图可直接打开这张图；
    - 右边"参数"对照表：分辨率、位深 · 色域、文件大小、拍摄时间、相机、镜头、
      修改时间；相似组还会多一行"画面相似度"（百分比越高越像）。
    - 点上方的"收起 / 展开"可以把预览区折叠，给表格让出更多空间。
    - 不是图片的文件（文档/视频等）用"扩展名色块"占位，参数表仍会显示大小与修改时间。
    - 提示：RAW（cr2/cr3/nef/arw…）会读取文件内嵌的 JPEG 预览来出缩略图；
      HEIC/AVIF 等系统缺少解码器的格式，缩略图可能显示为占位块，但查重不受影响。

六、相似图片（感知哈希）
    同一个照片经常被缩放、旋转、重压缩、转成别的格式、改名后存成多份，
    内容字节不同但画面一样。勾选"相似图片（感知哈希）"后，程序会给每张图算一个
    64 位"画面指纹"，按指纹距离判断相似：
    - 严格 ≤3：几乎一模一样，只有极轻微差异才算；
    - 标准 ≤6：默认，缩放/重压缩/轻微调色都能认出；
    - 宽松 ≤12：更宽松，构图相近的连拍、微调过的图也会被归到一起。
    相似组的保留规则建议选"分辨率最高的那份"（原片优先，导出的缩略图/压缩版被勾选删除）。
    注意：已经"字节级完全重复"的文件会归到精确重复组，不重复出现在相似组里。
    首次扫描要为每张图解码算指纹，图片很多时会比纯精确查重慢一些；
    想快就只勾"图片"类型 + "仅当前目录"，或先缩小范围再逐批处理。

七、怎么决定删哪些
    扫描完成后，每组会默认保留一份，其余副本自动打上勾（状态显示"待删除"）。
    "每组保留"有五种规则：
    - 最早修改的那份（默认）
    - 最新修改的那份
    - 路径最短的那份（通常是最初整理的那份）
    - 分辨率最高的那份（照片/相似图推荐：留住像素最多的原片）
    - 文件名最短的那份（名字最短，通常是原始文件；"- 副本""(1)"这类更长的名字会被勾选）
    你可以：
    - 直接改勾选：勾上的就会被删除；
    - 换一条保留规则：在"每组保留"下拉里点一下，表格会立刻按新规则重算勾选
      （点当前那条也行，"全不选"之后想恢复勾选就靠这个）；
    - 右键"只保留这一份"把这一组只留下当前行。
    右上角汇总会实时显示：重复组数、重复文件数、可释放空间、已勾选数量。

    1.4 新增"选择助手"（文件 → 选择助手… 或右键菜单），批量勾选不用一组组点：
    - 保留规则：最新修改 / 最早修改 / 路径最短 / 文件名最短 / 分辨率最高，五选一；
    - 每组保留份数：1～50 份（想留原片 + 一份备份就填 2）；
    - 作用范围：全部组 / 仅精确重复 / 仅相似图片；
    - 预览区实时算给你看：会勾选多少个文件、释放多少空间（按当前范围与规则），
      确认无误再点"应用选择"，表格里的勾选立刻按这个方案重排。

八、删除
    - "删除到回收站"（推荐）：走系统回收站，误删可以从回收站还原。
    - "永久删除"：直接抹掉、不可恢复，点之前会再弹一次红色警告确认。
    - 如果某一组的所有副本都被勾上，会额外提示"该内容将一份不剩"。
    - 文件被占用、没有权限、位于网络位置时可能删不掉，程序会在结果里列出
      失败原因和具体路径，可以改用永久删除或先关闭占用它的程序。

九、排序
    右上角"排序"下拉：按大小（大→小 / 小→大）、按时间（新→旧 / 旧→新）、
    按路径 A→Z。也可以直接点表头"大小""修改时间""完整路径"切换排序。
    组内行序跟随"每组保留"的规则，便于一眼看出留哪份、删哪份。

十、导出清单
    点"导出清单"可把当前结果存成 CSV（Excel 可直接打开）。
    1.4 起 CSV 顶部会先写 6 行本次扫描的汇总（模式、扫描时间、共扫描多少文件占多大、
    多少组、多少项可释放多少、总耗时），空一行再接表头：
    组号,文件名,完整路径,大小(字节),大小,修改时间,创建时间,状态。

十一、扫描设置说明
    - 扫描层级（默认"所有子目录（不限层级）"）：
        · 仅当前目录（不含子目录）：只看你添加的那个文件夹本身，里面的子文件夹全不看
        · 含 1 / 2 / 3 层子目录：往下钻 1 / 2 / 3 层
        · 所有子目录（不限层级）：一直钻到底（默认）
      只想查"总目录里的重复"就把层级调到"仅当前目录"，能显著减少扫描量。
    - 跳过隐藏文件与系统目录：默认开启，会跳过隐藏/系统属性的文件，
      以及 $RECYCLE.BIN、System Volume Information 等系统目录。
    - 忽略 0 字节空文件：默认开启。
    - 最小文件大小：单位是 MB，默认 0.001 MB（约等于 1 KB，与旧版默认一致），
      设 0 表示不限制；想只查大于 1 MB 的文件就直接填 1（小文件多为空壳，通常没必要查）。
    - 全文件扫描：勾上后不再看扩展名，任何文件都参与比对，
      改了名字、换了后缀、甚至没有后缀的文件也能被认出来；勾上时文件类型
      与"补充扩展名"会自动置灰（不再生效）。

    扫描层级会记在 settings.ini（scanDepth=0..4）里，下次打开沿用上次的选择。
    "相似图片"开关与阈值也会记住（scanSimilar=0|1、similarThreshold=3|6|12）。

十三、命令行用法（可选）
    文件查重工具.exe "D:\照片" "E:\备份" --scan
    --scan 表示启动后自动开始扫描；--sort=0..4 可指定默认排序
    （0 大小↓ 1 大小↑ 2 时间↓ 3 时间↑ 4 路径）。

十四、查重原理与准确性
    三级过滤，保证"内容真的相同"才判为重复：
    1) 先按文件大小分组，大小唯一的文件直接排除（绝大多数文件在这一步就被筛掉）；
    2) 对同尺寸文件取样指纹：头 8KB + 尾 4KB 的 MD5（8KB 以内的小文件即全文）；
    3) 指纹也相同的，再算全文 SHA-256 做最终确认。
    所以两个文件只要内容不同，即使名字一样、大小一样，也不会被判为重复。
